# 店舗IT 学習室

店舗のシステム問い合わせ対応を題材にした、4択・全問解説付きの学習用PWAです。初版は102問・8分野。参考サイトの問題文や画像は転載しておらず、講義内容から作ったオリジナル問題です。公式試験の過去問・網羅的な試験対策教材ではありません。

## 使い始める

Windowsでは、Node.js 22以上を用意し、このフォルダーの「起動.cmd」をダブルクリックします。表示された http://127.0.0.1:4173/store-it-quiz/ をブラウザーで開きます。起動したウィンドウを閉じるとローカルサーバーは終了します。

ターミナルから使う場合：

```sh
npm test
npm run build
npm start
```

追加ライブラリーのインストールは不要です。index.htmlの直接ダブルクリックでは問題データを読み込めない場合があるため、上記の方法か公開URLを使ってください。

## 機能

- 全問題・分野別・未回答・苦手（最後の回答が不正解）・お気に入りから出題
- 10問・20問・50問・全問、問題順のランダム化、選択肢のシャッフル
- 回答確定後に採点・解説、完了後に結果一覧と間違えた問題の復習
- 中断・再開、累計正答率、回答済み数、分野別進捗、最近の回答
- JSONによる履歴の書き出し・読み込み
- ホーム画面への追加、初回読み込み後のオフライン学習

履歴は端末・ブラウザー・サイトの接続先ごとのlocalStorageに保存します。端末間で自動同期はしません。ブラウザーのデータ削除や別の公開先へ移動する場合に備え、必要なら書き出してください。読み込みは現在の履歴を置き換えます。履歴は最新10万件まで読み込み可能です。

PWAのインストール操作・対応状況はブラウザーで異なります。初回アクセスはオンラインで行い、「使い方・データの保存」のオフライン準備完了を確認してください。ホーム画面に追加後も、更新の取得には通信が必要です。

## GitHub Pagesで公開する（まだ未公開）

1. GitHubにこのアプリ専用のリポジトリを作成します。
2. **このstore-it-quizフォルダーの中身**をリポジトリ直下へ配置します。上の階層の学習記録や個人資料を一緒に公開しないでください。
3. `main`ブランチへアップロードします。隠しフォルダーの `.github/workflows/pages.yml` も含めます。
4. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
5. **Actions → Publish learning app → Run workflow** を実行します。以後はmainへの変更で検証・生成・公開が実行されます。
6. ワークフロー完了後、PagesのURLを開きます。一般的には `https://ユーザー名.github.io/リポジトリ名/` です。

リポジトリ名の下で動くよう、アセット・manifest・Service Workerには相対パスを使用しています。独自ドメインは設定していません。アカウント・組織側でActionsやPagesが制限されている場合は、その設定確認が必要です。

参考：[GitHub公式：Pagesのカスタムワークフロー](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

生成済みの `dist/` も同梱しています。ブランチから公開する方式を選ぶ場合は、distの中身を公開対象に配置する方法もありますが、今後の問題追加を反映しやすい上記Actions方式を推奨します。

## 問題を増やす

編集対象は `content/questions.mjs` です。書式と運用は [問題追加ガイド](問題追加ガイド.md) を参照してください。追加後は `npm test` と `npm run build` を実行します。

この会話で今後の学習を続ける際は、学習記録・用語資料に加えて、この問題集も更新します。アプリが会話内容を自動収集するわけではなく、学習内容を確認して問題を追記する運用です。別の会話で再開する場合は、学習記録とこのガイドを読み込むよう依頼してください。

公開後は更新をGitHubへ反映するとActionsが新しい問題集を公開します。アプリの「問題集を更新」で最新版を確認できます。既存IDを維持すれば、問題追加後も過去の回答履歴を引き継げます。

## ファイル構成

- `content/questions.mjs`：問題データの編集元
- `public/`：画面、スタイル、アプリ処理、PWA設定
- `scripts/build.mjs`：検証済み問題集・アイコン・更新用キャッシュ番号を生成
- `scripts/serve.mjs`：PC内のローカルプレビュー
- `tests/`：問題形式と出題条件・履歴読み込みのテスト
- `dist/`：公開対象の生成済みファイル
- `.github/workflows/pages.yml`：GitHub Pagesへの公開処理

通常のUI操作に加え、対応ブラウザーでは読み取り専用のWebMCP進捗取得を提供します。アプリの利用にWebMCPは不要です。
